# mach4ml documentation

Welcome to the `mach4ml` documentation.

## Guides

- [Getting started](getting-started.md): install the package and run the recommended multi-file workflow.
- [Data format](data-format.md): understand the expected Biomomentum MACH-1 text export structure.
- [Workflows](workflows.md): run extraction, preprocessing, parameter extraction, modulus calculation, and QC plots.
- [API reference](api-reference.md): review all exported functions, arguments, return values, and examples.
- [Troubleshooting](troubleshooting.md): diagnose common extraction and analysis issues.

## Recommended reading order

1. Start with [Getting started](getting-started.md).
2. Check [Data format](data-format.md) to confirm your MACH-1 exports match the parser assumptions.
3. Use [Workflows](workflows.md) when you need manual control over preprocessing or QC.
4. Use [API reference](api-reference.md) when calling individual functions.
5. Use [Troubleshooting](troubleshooting.md) when something does not parse or results look unexpected.
